# 🧩 Level 1 — Torrent Inspection

## Objective

Download Batman (2022) safely from a simulated torrent website.

Only **ONE torrent is safe**.

All others contain indicators of:

* Malware
* Fake releases
* Impersonation
* Scam uploads
* Dangerous executable files

---

## What Players Learn

### Torrent Safety

* Seeder / Leecher analysis
* Trusted uploader verification
* Fake uploader detection
* File-size validation
* Suspicious filename recognition

### Malware Indicators

* `.exe`
* `.bat`
* `.scr`
* Password protected archives
* Fake codec installers
